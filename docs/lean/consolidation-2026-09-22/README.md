The original mathematical and formalization authors remain credited in each canonical page and project manifest. Original tested files and artifact digests are bound to immutable proof revisions. Shared verification tooling and the append-only permanent-ID registry are unchanged.

The integration imports per-problem subtrees and their required evidence/reference directories. It does not merge unrelated historical changes from the branch bases. The branch snapshots in the inventory are the authority for imported proof bytes; the integration receipt checks every tracked project file against those Git objects.
