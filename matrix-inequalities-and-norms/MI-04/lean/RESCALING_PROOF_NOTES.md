# MI-04 PSD rescaling proof map

Author implementation note, not an independent review. Source mathematics: Matthew J. Colbrook. Formalization: Sidney Holden with OpenAI Codex assistance. The explicit PSD-rescaling route replaces the source's simple-eigenvalue second-order perturbation calculation; it is an alternative formal-proof adaptation, not a claim that these intermediate matrices occur verbatim in the source.

- `Preservation` proves positive real scaling and actual unitary similarity preserve the full universal block property. Norm transport uses actual CStar/L2 unitary multiplication identities. It does not replace the norm by an entrywise norm.
- `PositiveLimit.eventually_posSemidef` proves the needed neighborhood fact rather than assuming it: a genuine positive-definite Hermitian matrix has a positive scalar order gap from the CFC spectrum; every Hermitian perturbation with norm less than that gap stays PSD. Matrix order is the actual PSD order and topology is the compatible L2 operator-norm topology.
- `Reflection` first proves the adjoint matrix retains the universal property by swapping actual blocks. For scalar-sum completions it turns the norm inequality into P<=2I, then an explicit sign/swap congruence gives the completion with the off-diagonal adjointed. The nonempty-dimension condition used to evaluate norm(I) is explicit.
- `Arrow` defines the polynomial-in-t matrix Q_t on the complete doubled finite index set. The cross-block's distinguished row is fixed while every other row has a factor t. The zero-limit Schur complement is computed exactly as the diagonal with distinguished entry 1-s²R. Its bottom diagonal is genuinely invertible because every weight is nonzero; the inverse is proved equal to the pointwise reciprocal by an actual right-inverse identity. Positivity and determinant nonvanishing prove the arrow matrix positive definite under s²R<1. The converse bound s²R<=1 follows from its Schur complement's diagonal. Exact matrix Hermiticity and continuity hold for every real t.
- `Rescaling` proves Q_t is congruent to the literal scalar-sum completion of t*s*X using the distinguished diagonal coordinate scaling. For t!=0 the scaling matrix is a genuine unit, proved using its determinant, so PSD is equivalent in both directions. For t>0 and s>0, the actual reflected completion therefore proves Q_t(X*) PSD. No extension of the singular function 1/t through zero is used: Q_t itself is defined polynomially at zero.
- `Threshold.weighted_threshold` starts from the positive-definite Q_0, obtains positivity in a full neighborhood, restricts to the genuine nontrivial right-neighborhood of zero, reflects each positive t, and uses the closed PSD cone to pass to Q_0(X*). Its Schur bound gives s²R(X*)<=1. This is the full all-dimensional weighted comparison step; no numerical testing, eigenvalue derivative, asymptotic remainder, or source theorem is left as a premise.
